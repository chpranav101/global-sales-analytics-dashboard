# Global Sales Analytics Dashboard

## Project Overview
This project is an interactive Power BI dashboard created using Excel sales data.

## Features
- Total Sales KPI
- Country-wise Sales Analysis
- Product-wise Revenue Analysis
- Sales Person Performance
- Monthly Sales Trends
- Boxes Shipped Analysis
- Interactive Filters/Slicers

## Tools Used
- Power BI
- Excel
- DAX
- Data Visualization
